【用户需求】
用户有一个工程 dandan-tui（YJL Linux TUI），其中内置了 argo（Cloudflare Tunnel）管理功能。
用户要求：
1) 先调研 GitHub 上是否有类似工程；
2) 把该 argo 管理功能单独拿出来，做成一个新的独立工程，方便自己使用。

【产品经理】
- 目标：把 dandan-tui 的 yjl-argo 子模块独立成一个单独的 GitHub 仓库，便于单独安装/维护/分发。
- 定位由用户确认为「原样独立化」：行为与现状一致，不做功能增强，不换技术栈。
- 安装方式由用户确认：保持 install.sh，不做 launch.sh 一行在线安装。
- 命名由用户确认：全盘保留（命令 yjl、服务 yjl-argo、路径 /etc/yjl-argo 等）。
- 仓库名 yjl-argo；本地就地以 D:\new-shell\wen\argo-yjl-dingzhi 作为仓库根。
- 许可证 MIT，署名 xiaofeixoa。
- 本次不加 GitHub Actions CI。
- 交付范围：代码 + README + LICENSE + 文档四件套（设计.md/框架.txt/使用说明.md/codex.txt）+ git init 首次提交；
  推送 GitHub 单独确认（需要凭证或仓库已存在）。

【调研：GitHub 类似工程】
- Misaka-blog/argo-script：CloudFlare Argo Tunnel 一键管理脚本。同为菜单式 bash 管理器，
  偏“装 tunnel + 配 ingress”，不带 Token 多入口表管理。
- cloudflare/cloudflared：官方客户端，底层依赖，非同类。
- fscarmen/ArgoX、yonggekkk/argosbx、eooce/Argo：Argo + Xray/sing-box 代理隧道，定位不同
  （跑 VLESS/VMess 代理协议）。
- 各类“远程托管固定隧道脚本”博客方案：调用 Zero Trust API 自动建隧道，多为单次脚本。
结论：**纯 cloudflared 隧道菜单管理器 + Token 模式 + 多 ingress 入口表 + systemd/OpenRC 双 init + 健康检查**
这个组合，GitHub 上没有现成等价物，值得独立成工程。

### 2. 语法 / 功能测试
环境：Windows + Git Bash 5.3.9 (x86_64-pc-cygwin) + git 2.54.0.windows.1

| 命令 | 结果 | 结论 |
| --- | --- | --- |
| bash -n yjl-argo.sh | exit 0 | PASS |
| sh -n install.sh | exit 0 | PASS |
| bash -n tests/test.sh | exit 0 | PASS |
| bash -n tests/fake-cloudflared.sh | exit 0 | PASS |
| bash tests/test.sh | exit 1 | 见下（环境限制） |

**问题**：cygwin 在本机文件系统上无法 chmod，上游测试夹具里的 `install -d -m 700`
报 `Permission denied`。参数拼装、源码契约断言、README 断言三段在失败前均已通过。

**修复（验证手段，不修改交付物）**：用导出的 shell 函数桩掉 `install`/`chmod`，
在无权限语义的 Windows 上重跑完整测试：

    bash -c 'install() { mkdir -p "$4"; }; chmod() { return 0; }; export -f install chmod; bash tests/test.sh'

**结果**：`All YJL Argo tests passed.`（安装集成测试因非 root 按设计跳过）

**补充**：另用等价脚本单独验证路由表增删改逻辑（临时目录 + 桩），
`routes.tsv` 实测内容为 `panel\tpanel.example.com\t/admin\thttp://127.0.0.1:8081\tno`，
与预期逐字节一致 → PASS。

**本机无法验证的部分（如实记录）**：
- 权限位（config.env/routes.tsv 600、安装产物 755）——Windows 无 POSIX 权限语义；
- 真实 systemd / OpenRC 服务拉起与开机自启；
- 真实 Cloudflare 隧道连通性与公网健康检查。
以上需在真实 Debian/Ubuntu 与 Alpine 主机上补测。
